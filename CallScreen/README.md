# CallScreen (One UI ոճի զանգի էկրան WhatsApp, Viber, Telegram, Instagram և Messenger-ի համար)

Այս նախագիծը լիարժեք պատրաստ է **Android Studio**-ով բացելու կամ **GitHub Actions**-ի միջոցով ավտոմատ `.apk` ֆայլ ստանալու համար։

## Ինչ է ավելացվել և բարելավվել կոդում
1. **Պահեստային `PendingIntent` (`CallListenerService.kt`)** — եթե մեսենջերի ծանուցման կոճակի անվանումը չհամընկնի Regex-ի հետ, կանաչ սահիչը ավտոմատ կօգտագործի `fullScreenIntent` կամ `contentIntent`, որպեսզի զանգը միշտ բացվի։
2. **Զանգահարողի նկարի (Avatar) և զանգի տեսակի արտածում (`CallListenerService.kt` և `CallActivity.kt`)** — ծանուցումից ավտոմատ վերցվում է զանգահարողի պրոֆիլի նկարը (`getLargeIcon()`) և ցուցադրվում շրջանաձև շրջանակի մեջ (իսկ եթե նկար չկա՝ ցուցադրվում են անվան սկզբնատառերը), ինչպես նաև տարբերակվում է ձայնային ու տեսազանգը։
3. **Սպիտակ վեկտորային հեռախոսի պատկերակ և պուլսացիա (`CallActivity.kt`)** — գունավոր `📞` էմոջիի փոխարեն օգտագործվում է մաքուր սպիտակ հեռախոսի պատկերակ (`android.R.drawable.sym_action_call`), ավելացվել է արտաքին օղակի սահուն անիմացիա և թեթև վիբրացիա սահեցնելիս։
4. **Կարգավորումների կարգավիճակ և «Փորձարկել զանգի էկրանը» կոճակ (`MainActivity.kt`)** — հիմնական էկրանին երևում է, թե որ թույլտվություններն են արդեն միացված, ցուցադրվում է ընտրված հետնանկարի նախադիտումը, և ավելացվել է փորձնական զանգի կոճակ՝ առանց իրական զանգի սպասելու էկրանը ստուգելու համար։
5. **Լիարժեք Gradle կառուցվածք և Adaptive Icon** — ավելացվել են `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties` և `@mipmap/ic_launcher` ռեսուրսները։

## Տարբերակ 1. Ինչպես ստանալ APK-ն Android Studio-ով
1. Unzip արեք `CallScreen-Android-Project.zip` ֆայլը։
2. Բացեք **Android Studio** -> **Open** և ընտրեք բացված պանակը։
3. Սպասեք մի քանի վայրկյան, մինչև **Gradle Sync**-ը ավարտվի։
4. Վերևի մենյուից ընտրեք **Build → Build Bundle(s) / APK(s) → Build APK(s)**։
5. Պատրաստի ֆայլը կգտնեք `app/build/outputs/apk/debug/app-debug.apk` հասցեում։

## Տարբերակ 2. Ինչպես ստանալ APK-ն առանց Android Studio-ի (GitHub-ի միջոցով՝ անվճար)
1. Մտեք [GitHub](https://github.com) և ստեղծեք նոր դատարկ Repository։
2. Բեռնեք (Upload files) այս պանակի բոլոր ֆայլերը այդ Repository-ի մեջ և սեղմեք **Commit changes**։
3. Մտեք **Actions** բաժին, ընտրեք **Build CallScreen APK** աշխատանքը։
4. 1–2 րոպեից ներքևի **Artifacts** բաժնից ներբեռնեք պատրաստի `CallScreen-debug-apk` ֆայլը և տեղադրեք հեռախոսի մեջ։
